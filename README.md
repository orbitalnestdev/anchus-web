## 📸 Vista General del Proyecto

La plataforma incluye todas las secciones del mockup maquetadas con precisión pixel-perfect:

1. **Header & Top Bar**:
   - Barra de acento verde sage (`#a2ba9e`).
   - Isologotipo oficial "*ANCHUS Trip of Joy*".
   - Navegación principal en fuente `Jost` y botón cápsula `QUIERO SER CLIENTE`.
   - Menú de hamburguesa responsivo para dispositivos móviles.

2. **Hero Banner**:
   - Arte principal `57.png` / `hero_full.png` (2309x1043 px) a ancho completo de pantalla (100% full-width).
   - Botón en cápsula `VER PRODUCTOS` superpuesto en tono verde agua.
   - Efecto dinámico de scroll-pan & framing.

3. **Presentación de Temporada**:
   - `PRESENTAMOS PRIMAVERA VERANO 2027` con tipografía `Jost` ultra-espaciada (`letter-spacing: 0.28em`).
   - Textos descriptivos en tono marrón orgánico cálido (`#5c483c`).

4. **Cómo Comprar por Mayor**:
   - Fondo beige/crema cálido (`#faf4e6`) con regla divisoria.
   - Pasos `01 REGISTRATE`, `02 ARMÁ TU COMPRA` y `03 RECIBILA` en verde sage.
   - Enlace directo a la **Zona Privada Mayorista** (`https://anchus.com.ar/mayorista/zonaprivada.php`).

5. **La Colección**:
   - Grilla de 5 tarjetas (`RECIÉN NACIDO`, `BEBÉS`, `NENAS`, `NENES`, `COLEGIAL`).
   - Franja superpuesta semitransparente de etiqueta crema (`#f6edd0`) posicionada en la base sin tapar los pies de los niños.

6. **Propuesta de Valor / Beneficios**:
   - Sección verde sage completa (`#a2ba9e`) con 3 columnas (`FABRICACIÓN PROPIA`, `CURVA COMPLETA`, `ASESORAMIENTO`) y líneas divisoria blancas.

7. **Lookbook**:
   - Grilla asimétrica de 3 columnas con 5 fotos (`64.png` a `68.png`) y bordes redondeados (`10px`).
   - Encuadre completo desde la cabeza hasta las zapatillas/pies.

8. **Vení a Visitarnos (Locales)**:
   - Tarjetas blancas redondeadas (`18px`) para las sucursales de *Wilde*, *Lanús*, *Quilmes* y *Lomas de Zamora*.

9. **Red Mayorista Anchus**:
   - Banner destacado marrón oscuro (`#5c483c`) con enlace directo a WhatsApp.

10. **Footer**:
    - Pie de página institucional en 4 columnas con enlaces a **Tienda Minorista**, **Catálogo Mayorista**, **WhatsApp**, **Instagram** y **Facebook**.

## 🛠️ Tecnologías Utilizadas

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio**:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd Anchus
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo**:
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

4. **Compilar para producción**:
   ```bash
   npm run build
   ```
